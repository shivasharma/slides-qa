## AI Study Assistant – IS247 Java

### Project Description

In this project, you will use an AI-powered study assistant to ask questions about **Java lecture slides** and receive instant explanations.

Instead of manually searching slides, you can type questions such as:
- “What is inheritance?”
- “Explain method overriding”
- “Give an example of polymorphism”

The system uses artificial intelligence to analyze the lecture material and generate clear, student-friendly answers.

---

### Learning Objectives

- Understand how AI can support learning
- Improve comprehension of Java OOP concepts
- Experience real-time AI-driven question answering
- Learn how frontend and backend systems communicate

---

### How to Use

1. Open the study assistant webpage
2. Type your Java-related question
3. Press **Enter**
4. Read the AI-generated explanation

---

### Rules

- Ask questions related to Chapter  only
- Use this tool as a **learning aid**, not a shortcut
- Verify important concepts with lecture notes

---

### Outcome

By using this tool, students should gain:
- Better conceptual understanding
- Faster revision
- Increased confidence with Java topics
